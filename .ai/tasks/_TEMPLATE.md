# [loai] Tiêu đề ngắn của task

> **Loại:** bug | change | refactor | db | spike
> **Ngày tạo:** YYYY-MM-DD · **Người làm:** ... · **Người yêu cầu:** ...
> **Trạng thái:** Todo | Doing | Blocked | Done
> **Progress aggregation:** v1
> **Liên quan:** step / plan / issue / commit / PR (BE, FE, root)
> **Phạm vi:** repo/module/file chính bị ảnh hưởng

## 1. Mô tả
- bug: hiện tượng, cách tái hiện, môi trường.
- change: yêu cầu cũ → yêu cầu mới, lý do.
- refactor / db: phạm vi, lý do.
- spike: câu hỏi cần trả lời.

## 2. Phân tích
- bug: nguyên nhân gốc (file:dòng).
- spike: các phương án, ưu/nhược.

## 3. Features / Milestones
- [ ] Feature 1 — mô tả kết quả có thể xác minh.
- [ ] Feature 2 — mô tả kết quả có thể xác minh.

Chỉ đặt checklist feature/milestone trong mục này. Giữ các mục đã hoàn thành; không xóa feature chỉ để làm thay đổi tỷ lệ tiến độ. Có thể bổ sung feature khi scope task thực sự mở rộng.
Nếu trạng thái task là `Done`, tất cả feature checklist có theo dõi phải được đánh dấu hoàn thành.

## 4. Cách làm
- File đã tạo / sửa.
- Lệnh đã chạy (build, migration...).

## 5. Kiểm tra
- Test đã chạy và kết quả (số check pass, test mới chống tái phát).

## 6. Việc còn lại
- Việc chưa xong, đang chờ ai / việc gì. Ghi "Không" nếu đã xong hết.

## 7. Evidence và cập nhật
- Commit / PR đã merge:
- CI / workflow run và kết quả:
- Ngày cập nhật cuối: YYYY-MM-DD
- Ghi rõ phần nào đã xác minh, phần nào mới chỉ được triển khai hoặc đang chờ xác minh.
